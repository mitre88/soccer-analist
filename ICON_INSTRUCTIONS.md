# App Icon Instructions

## Required Icon

The app icon should be created as a **1024x1024px PNG** file with the following specifications:

### Design Guidelines

**Theme**: Minimalist, professional, black and white

**Concept**: Soccer ball with AI/brain elements

**Style**:
- Clean, modern design
- High contrast black and white
- Geometric and sharp
- Suitable for both light and dark backgrounds

### Suggested Design Elements

1. **Primary Element**: Soccer ball icon (simplified)
2. **Secondary Element**: AI/neural network pattern or brain icon
3. **Color Scheme**:
   - Background: Pure black (#000000)
   - Foreground: Pure white (#FFFFFF)
   - Optional: One accent in grayscale

### Design Options

#### Option 1: Minimalist Soccer Ball
```
- Black background
- White soccer ball (outlined or filled)
- Subtle AI circuit pattern overlay
```

#### Option 2: Abstract S + Ball
```
- Black background
- Stylized "S" incorporating a soccer ball
- Modern, geometric design
```

#### Option 3: Brain + Ball Fusion
```
- Black background
- Soccer ball with brain/neural network inside
- Clean line work
```

## Creating the Icon

### Using Figma (Recommended)

1. Create 1024x1024px artboard
2. Set background to black
3. Design icon centered
4. Export as PNG (2x for crisp quality)
5. Name: `icon-1024.png`

### Using Adobe Illustrator

1. New document: 1024x1024px
2. Design in vector format
3. Export as PNG
4. Place in assets folder

### Using Online Tools

**Canva**:
1. Create custom design (1024x1024px)
2. Use black background
3. Add white geometric shapes
4. Download as PNG

**Photopea** (Free Photoshop alternative):
1. File → New → 1024x1024px
2. Design your icon
3. Export as PNG

## File Location

Once created, place the icon at:
```
StoicIA/StoicIA/Resources/Assets.xcassets/AppIcon.appiconset/icon-1024.png
```

## Testing

After adding the icon:
1. Open project in Xcode
2. Check Assets.xcassets → AppIcon
3. Verify icon appears in all sizes
4. Test on device/simulator
5. Check home screen appearance

## App Store Requirements

- **Size**: Exactly 1024x1024 pixels
- **Format**: PNG (no alpha channel)
- **Color Space**: sRGB or P3
- **No Transparency**: Must be fully opaque
- **No Rounded Corners**: iOS adds these automatically
